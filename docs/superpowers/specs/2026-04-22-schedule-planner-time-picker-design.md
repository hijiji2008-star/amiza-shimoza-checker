# スケジュールプランナー — グラフタップ式時刻入力 設計書

## 概要

`schedule-planner.html` の時刻入力をドーナツグラフを直接タップして設定できるよう改善する。

- ドーナツリングをクリック/タップ → 開始・終了時刻をセット
- 30分スナップ
- 設定した時刻はサイドバーフォームに自動入力される

---

## インタラクション仕様

### 状態管理

各SVGグラフ（AM / PM）が独立した `tapState` を持つ。

```
tapState = null
  → 次クリック = START 確定

tapState = { startMin: number }
  → 次クリック = END 確定 → フォームに自動入力
```

**リセット条件:**
- ESCキーを押す
- グラフのリング外をクリックする

### ホバーインジケーター

- `mousemove` / `touchmove` でリング上の座標を検出
- 座標 → 角度 → 時刻 に変換し、30分スナップ
- 光るドット（白/半透明）をリング上の最近傍30分位置に表示
- 判定範囲: `INNER_R - 10` 〜 `R + 10`（タッチ操作のため広め）
- `tapState` がある場合、ホバー中はSTARTから現在位置までのゴースト弧を描画

### クリック処理

**1回目クリック（START）:**
- リング上の判定範囲内であれば START 確定
- 青い点（`#38bdf8`）をリング上に固定表示
- `tapState = { startMin }` にセット

**2回目クリック（END）:**
- END 確定
- 緑の点（`#34d399`）をリング上に固定表示
- `inp-start.value` / `inp-end.value` に時刻文字列を自動入力
- `inp-name.focus()` でフォームにフォーカス移動
- `tapState = null` にリセット（次の活動を連続で追加できる）

---

## 30分スナップのロジック

```
角度(deg) → 分 = periodStart + (angleDeg + 90) / 360 * 720
スナップ後 = Math.round(分 / 30) * 30
範囲クランプ = 0 〜 1440
```

---

## UI変更点

| 要素 | 変更内容 |
|------|---------|
| `<input type="time">` | 残す（手動修正フォールバック） |
| SVG（AM/PM両方） | `mousemove`, `touchmove`, `click`, `touchend` を追加 |
| `drawBase()` | ホバードット・START点・END点・ゴースト弧の描画を追加 |
| `renderCharts()` | tapState を渡してインジケーターを描画 |
| `addActivity()` | 変更なし（フォーム値を読むだけ） |
| ヒントテキスト | 「グラフをタップして開始・終了時刻を設定」に更新 |

---

## スコープ外

- 1分単位のスナップ（今回は30分固定）
- ドラッグによる伸縮
- AM→PMをまたぐ活動をグラフタップで設定（手動入力で対応）
