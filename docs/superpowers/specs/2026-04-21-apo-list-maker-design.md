# アポリストメーカー 設計書

**作成日:** 2026-04-21  
**バージョン:** 1.0.0（プロトタイプ）

---

## 概要

派遣会社の営業担当者が、アポイントメント電話（アポデン）の架電先リストを効率よく作成するためのツール。  
Indeed Japanから求人掲載中の企業情報を自動収集し、派遣会社の求人を除外した上でリストを生成する。

---

## ターゲットユーザー

- 派遣会社の営業担当者
- 架電先の企業を手動で探す手間を省きたい人
- 「今まさに求人を出している＝人手不足」の会社に優先的にアプローチしたい人

---

## アーキテクチャ

**構成：Python（Flask）+ HTML テンプレート、ローカル実行**

```
実行: python apo_list_maker.py
  ↓
ローカルWebサーバー起動（http://localhost:5000）
  ↓
ブラウザでフォームを表示
  ↓
区・業種を選んで「リスト作成」ボタン
  ↓
Indeed Japanをスクレイピング（requests + BeautifulSoup）
  ↓
フィルタリング・重複排除
  ↓
結果をブラウザに一覧表示
```

**ファイル構成**

```
apo_list_maker.py       # Flaskサーバー兼スクレイパー
templates/
  index.html            # フォーム画面 + 結果表示画面
```

**使用ライブラリ（すべて無料・pip install）**

- `flask` — ローカルWebサーバー
- `requests` — HTTP通信
- `beautifulsoup4` — HTML解析

## 画面設計

### フォーム画面

- **エリア選択**（複数選択可）：東京23区すべてをチェックボックスで表示
- **業種選択**（複数選択可）：販売・小売、倉庫・物流、製造、飲食、事務、IT・通信
- **取得件数上限**：50件 / 100件 / 200件（ドロップダウン）
- **リスト作成ボタン**：クリックでスクレイピング開始

### 結果画面

| 列 | 内容 |
|---|---|
| # | 連番 |
| 会社名 | 企業名 |
| 業種 | 検索した業種 |
| エリア | ○○区 |
| 公式HP | クリックで開くリンク（取得できない場合は「—」） |
| Indeed掲載ページ | 求人ページへのリンク（会社名・求人内容の確認用） |
| 求人タイトル | Indeed上の職種名（参考） |

- **全コピーボタン**：テーブル全体をTSV形式でクリップボードにコピー（Excelに直接貼り付け可能）
- 取得件数と除外件数をヘッダーに表示（例：「38件表示（派遣会社 12件除外）」）

## データ取得ロジック

### Indeed Japan 検索URL

```
https://jp.indeed.com/jobs?q={業種キーワード}&l={区名}+東京都
```

複数の区・業種の組み合わせを順番に検索し、結果をまとめる。

### 取得項目

- 会社名
- 求人タイトル（参考表示用）
- 公式HP URL（Indeed掲載がある場合のみ）

### 派遣会社フィルタリング（除外条件）

以下のいずれかに該当する求人を除外する：

1. 雇用形態に「派遣」が含まれる
2. 会社名に以下のキーワードが含まれる：
   - 派遣、スタッフィング、テンプ、パーソル、アデコ、マンパワー、リクルートスタッフ、フルキャスト、バイトル、ランスタッド、エン・ジャパン（派遣部門）

### 重複排除

同一会社名が複数の区・業種で登録された場合、1件にまとめる（最初に取得したエリア・業種を採用）。

### ブロック対策

- リクエスト間に1〜2秒のランダム待機
- ブラウザに見せかけるUser-Agentヘッダーを付与
- ブロック検出時は5秒待機して再試行（1回まで）

### ターミナル進捗表示

```
🔍 新宿区 × 販売 を検索中...（12件取得）
🔍 渋谷区 × 倉庫 を検索中...（8件取得）
⚠️  ブロックを検出、5秒待機中...
✅ 完了！38件（派遣除外後）→ ブラウザを開きます
```

---

## 制約・注意事項

- **電話番号はIndeedに掲載されていないため取得しない**（公式HPから手動確認）
- IndeedのToSによりスクレイピングは本来禁止されており、**個人利用・プロトタイプの範囲**での使用に限る
- Indeedのサイト構造変更により動作しなくなる場合がある
- 取得できる公式HP URLはIndeedが掲載している場合のみ（すべての企業で取れるわけではない）
