# Mountain Timer — Design Spec

**Date:** 2026-04-29  
**Status:** Approved

---

## 概要

登山×天気変化をビジュアルにしたカウントダウンタイマー。時間の経過とともに天気と時刻が変わり、ハイカーが山を登って頂上に達し、下山して戻ってくる。

---

## ファイル構成

```
projects/mountain_timer/index.html
```

単一HTMLファイル。CSS・JSすべてインライン。依存ライブラリなし。ブラウザで開くだけで動作。

---

## SVGシーン構成

### 登場要素

| 要素 | 詳細 |
|------|------|
| 空 | グラデーション。天気・時刻に応じて連続変化 |
| 雨雲 | 出発時に表示。経過とともにフェードアウト |
| 雨粒 | JSで生成した線要素。数が徐々に減る |
| 太陽 | 下山中に右から左へ移動しながら沈む |
| 虹 | 頂上付近（経過40〜60%）でフェードイン→フェードアウト |
| 遠景の山 | 2つ。背景として固定 |
| メイン山 | 中央。左裾→頂上→右裾のパスをハイカーが移動 |
| 木々 | 麓の左右に配置。固定 |
| 頂上フラグ | 常時表示 |
| ハイカー | 経過%に応じてパス上を移動。頂上でバンザイポーズ |
| 足跡点線 | 通過済みのパスを点線で描画（往復分残る） |

### 天気ステートマシン

経過%（0〜100）に基づいてすべての要素を連続的に補間する。

| 経過% | 天気 | 空の色 | 雨 | 虹 | 太陽 |
|-------|------|--------|----|----|------|
| 0% | 雨（強） | ダークグレー `#1a2535` | 最大密度 | なし | 非表示 |
| 40% | 雨（弱） | グレー `#2d4a6a` | 密度20% | なし | 非表示 |
| 50% | 快晴（頂上） | 明るい青 `#5bafd6` | 0% | 最大 | 高い位置 |
| 80% | 晴れ→夕方 | オレンジ `#c2440a` | 0% | なし | 地平線付近 |
| 100% | 夕焼け | 深紅〜暗 `#0f1a35` | 0% | なし | 沈んだ状態 |

### ハイカーの移動パス

```
登り: START(左裾) → PEAK(頂上)  ← 経過 0〜50%
下り: PEAK(頂上) → END(右裾)   ← 経過 50〜100%
```

頂上到達時（経過48〜52%）のみバンザイポーズ。それ以外は歩行アニメ（腕・足を小刻みに振る）。

## UI仕様

### レイアウト（縦並び）

```
┌────────────────────────────┐
│      SVGシーン（480×300）    │
│      大きい時刻表示          │
│      フェーズラベル           │
├────────────────────────────┤
│  [5分] [10分] [15分] [20分]  │  ← プリセットボタン
│   分▼   秒▼    ▶    ↺      │  ← 入力 + コントロール
└────────────────────────────┘
```

### 時間入力

- 分プルダウン: 0〜99分
- 秒プルダウン: 0, 15, 30, 45秒
- プリセットボタン: **5分 / 10分 / 15分 / 20分**（クリックで分・秒を自動セット）

### コントロール

| ボタン | 動作 |
|--------|------|
| `▶ スタート` | タイマー開始。ラベルが `⏸ 一時停止` に変わる |
| `⏸ 一時停止` | タイマー停止。ラベルが `▶ スタート` に戻る |
| `↺ リセット` | タイマーをセット時間に戻し、シーンをリセット |

### タイマー終了時

- ハイカーがゴール地点（右裾）に到着した状態で停止
- ブラウザの `AudioContext` でビープ音を鳴らす
- テキスト表示なし

---

## デザイン

- **背景**: `#0d1117`（ダークモダン、他ツールと統一）
- **フォント**: 時刻表示は `Courier New`（モノスペース）
- **カラーアクセント**: `#f59e0b`（アンバー）を足跡・進捗バーに使用
- **シーン全体の雰囲気**: ダークナイト→昼間→夕焼けへの自然な変化

---

## 技術メモ

- 雨粒: `<line>` 要素をJSで動的生成。`requestAnimationFrame` でy座標をアニメ
- 天気補間: `lerp(a, b, t)` を各要素の色・透明度・位置に適用
- 足跡: `<polyline>` の `points` をtickごとに追記
- 歩行アニメ: `Math.sin(frame * 0.4)` で腕・足を振る
- ビープ音: `AudioContext.createOscillator()` で短い通知音
