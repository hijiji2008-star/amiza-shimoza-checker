# カフェイン残量トラッカー — 設計仕様

## 概要

コーヒーなどカフェイン飲料の摂取時刻を入力すると、体内カフェイン残量の推移を24時間グラフで可視化する単一HTMLファイルのWebツール。

**主目的:** 体内推移をグラフで眺めて楽しむ（睡眠最適化・タイミング管理は対象外）

---

## アーキテクチャ

- 単一HTMLファイル（Vanilla JS・外部依存なし）
- ファイル名: `caffeine_tracker/index.html`
- 他プロジェクト（上座下座チェッカー、スケジュールプランナー等）と同じ構成

---

## UI構成

```
┌─────────────────────────────────┐
│  caffeine tracker               │  ← ヘッダー
├─────────────────────────────────┤
│  DRINK LOG                      │
│  [ドリンク選択▼] [時刻] [+追加]  │  ← 入力エリア
│  ─────────────────────────────  │
│  09:00 ☕ ドリップコーヒー  95mg ✕│
│  13:30 🍵 緑茶            30mg ✕│  ← ログリスト
├─────────────────────────────────┤
│  CAFFEINE LEVEL (mg)            │
│  [24時間グラフ SVG]              │  ← グラフ
│  現在 87mg   深夜0:00時点 12mg    │  ← バッジ
└─────────────────────────────────┘
```

---

## グラフ仕様

- **X軸:** 今日の 0:00〜翌 0:00（24時間）
- **Y軸:** カフェイン残量（mg）、上限は24時間分の計算結果の最大値（最低100mgを下限として設定）
- **描画:** 30分刻みで計算した点を滑らかな曲線（SVG path）で結ぶ
- **塗り:** 曲線下をグラデーション塗り（インディゴ→透明）
- **現在時刻インジケーター:** なし

---

## カフェイン計算ロジック

半減期モデル（指数減衰）:

```
残量(t) = Σ mg_i × 2^(-(t - t_i) / 5.5)
```

- `t`: 計算対象時刻（時間単位）
- `t_i`: 各摂取時刻（時間単位）
- `mg_i`: 各摂取量（mg）
- 半減期: **5.5時間**（固定・科学的根拠値）
- `t < t_i` の摂取分は無視（摂取前は寄与ゼロ）

## データ永続化

- **保存先:** `localStorage`（キー: `caffeine_log`）
- **形式:**
  ```json
  {
    "date": "2026-04-30",
    "entries": [
      { "drink": "drip_coffee", "label": "ドリップコーヒー", "mg": 95, "time": "09:00" },
      { "drink": "green_tea",   "label": "緑茶",             "mg": 30, "time": "13:30" }
    ]
  }
  ```
- **日またぎ:** ページ読み込み時に保存日付と当日を比較し、不一致なら自動リセット

## スコープ外

- 就寝時刻ライン
- 半減期カスタマイズ
- 複数日の履歴
- スマホ以外の特別対応（レスポンシブは対応するが、PCレイアウト最適化は行わない）
